# 红树林超能力大冒险 · 小学生科普互动

单文件网页互动作品：帮「小红树」在潮间带通过五重生存考验，解锁红树的超能力法宝。

**直接玩**：用浏览器打开 `mangrove-adventure.html` 即可（无需联网、无外部依赖，约 103 KB）。

## 玩法

- **五关挑战**：高盐海水 → 泌盐｜缺氧淤泥 → 呼吸根｜潮水冲刷 → 胎生｜台风巨浪 → 支柱根｜浑浊污水 → 根系净化
- **对比表逐行浮现**：每过一关，「普通植物 ❌ vs 红树植物 ✅」对应一行解锁
- **场景会随通关变化**：叶片冒出盐晶、泥面长出呼吸根、胎生胚轴掉落发芽
- **涨潮/退潮切换**：看呼吸根被海水淹没又露出
- **7 个知识热点**：树干（名字由来）、落叶（食物工厂）、小鱼（大海幼儿园）、招潮蟹（滩涂居民）、滩涂（蓝碳仓库）、⚠️（红树林危机）、树冠（红树家族，通关解锁）
- **红树图鉴**：秋茄、桐花树、白骨壤、木榄、海桑、红树 6 个树种
- 支持键盘 1/2/3 快选、Enter 过场；⛶ 全屏适合课堂投影；单屏布局，答题不用滚动

## 文件结构

| 文件 | 说明 |
|---|---|
| `mangrove-adventure.html` | **成品**（单文件，图标已全部内联，可直接分发） |
| `mangrove-adventure.src.html` | 源文件（图标用 `{{ic:名称}}` 占位） |
| `mangrove-icons/*.svg` | 29 个手绘扁平风 SVG 图标 |
| `build_icons.py` | 构建脚本：把图标 base64 内联进源文件，生成成品 |

## 重新构建

改了源文件或图标后，跑一句即可重新生成成品：

```bash
python3 build_icons.py
```
